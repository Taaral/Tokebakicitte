# Textes pour la page CurseForge

## Résumé (une ligne)

Des citations québécoises random dans ton chat : au login dans la guilde, ou quand tu veux avec /tokebec.

## Description

Coller le texte ci-dessous dans l'éditeur de description de CurseForge.

---

**Tokébakicitte** fait parler ton personnage en bon québécois.

*« Tequila, Heineken, pas l'temps d'niaiser! »*

### Fonctionnalités

- **117 citations** : expressions classiques, mèmes québécois et quelques clins d'œil à Azeroth
- **Citation au login** dans le chat de guilde, une seule fois par connexion
- **Citation sur demande** avec `/tokebec` dans ton chat actif : dire, groupe, raid, guilde, chuchotement ou canal
- **Cycle** : chaque citation est dite une fois avant de recommencer
- **Favoris** ⚜ et **tes propres citations**
- **Fenêtre d'options** sur fond de drapeau du Québec
- **Bouton sur la minicarte**
- **Anti-spam** : 5 secondes minimum entre deux envois

### Commandes

- `/tokebec`, `/tokebak` ou `/qc` : dit une citation dans ton chat actif
- `/tokebec options` : fenêtre des favoris et options
- `/tokebec guilde` : dit une citation dans la guilde
- `/tokebec fav` : ajoute/retire la dernière citation des favoris
- `/tokebec auto` : active/désactive la citation au login
- `/tokebec minimap` : affiche/cache le bouton de la minicarte
- `/tokebec test` : affiche une citation pour toi seulement

### Bouton de la minicarte

Clic gauche : options. Clic droit : dire une citation. Glisser : déplacer.
